# Mausam App

A runnable React + TypeScript + Vite prototype for the Mausam personalized weather app.

## Run in VS Code

1. Install Node.js (LTS) if you do not already have it.
2. Extract this folder.
3. Open the `mausam-app` folder in VS Code.
4. Open the VS Code terminal.
5. Run:

```bash
npm install
npm run dev
```

6. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Included

- Splash
- Language selection: English, Hindi, Marathi
- Location setup
- Guest / login / mock OTP
- Personalized homepage
- Hourly forecast
- 7-day forecast
- Weather details
- Alerts
- Notifications
- Map placeholder with switchable layers
- Saved locations
- Homepage customization
- Light / dark / system theme
- Responsive mobile/tablet/desktop layout
- LocalStorage persistence for theme/language/preferences
